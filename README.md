# Pet Shop Dev - Site Fictício

este é um projeto de uma loja fictícia de pet shop desenvolvido em **next.js**.

## tecnologias usadas

- **next.js** - framework react para desenvolvimento fullstack
- **tailwindcss** - estilização rápida e responsiva
- **embla-carousel-react** - carrossel para mostrar serviços e depoimentos
- **aos** - animações ao scroll
- **phosphor-icons** - ícones usados no site (whatsapp, etc)
- **lucide-react** - ícones adicionais (check, map pin, etc)

## funcionalidades

- seções de destaque com imagens e texto
- carrosséis de serviços e depoimentos
- integração de ícones com phospor-icons e lucide-react
- botões de contato via whatsapp
- lista de parceiros e rodapé com contatos e redes sociais

## como rodar

1. clonar o repositório
2. rodar `npm install` para instalar dependências
3. rodar `npm run dev` para iniciar o servidor de desenvolvimento

o site estará disponível em `http://localhost:3000`
